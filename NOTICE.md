# Source and data provenance

This directory is a code-only staging folder for HGIG. The training pipeline
was adapted from the author's earlier local research implementation, which
included components and experimental conventions from the public implementation
accompanying Liu et al., *Generative Recommender with End-to-End Learnable Item
Tokenization* (SIGIR 2025). The fixed-SID code path, EAPM, and RCBR are presented
here as the HGIG implementation; this notice does not assert that every shared
utility or backbone idea is original to HGIG.

No upstream dataset, pretrained checkpoint, RQ-VAE implementation, or generated
SID catalog is included. Users must supply those artifacts under the terms of
their respective sources and describe their provenance in experimental reports.

An open-source license has **not** been selected for this staging folder. Before
publishing it as an openly licensed GitHub repository, verify the licenses and
attribution requirements of any retained adapted code and choose a compatible
license. This notice is not a substitute for the original licenses or citations.
